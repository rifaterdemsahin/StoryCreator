# Rewrite Strategy

## Target Changes
- **Tone:** Slightly more conversational and "insider" tone. Less textbook, more "mentor".
- **Analogy Refresh:** Use everyday examples where possible to ground technical concepts.

## Global Rewrite Rules
- **Transitions:** Avoid standard "In this video..." where possible. Use active voice: "We're going to tackle..."
